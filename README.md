## 🚀 البدء السريع

### الطريقة الأولى: فتح مباشر في المتصفح

1. قم بتنزيل ملف `python_book.html` (أو `index.html`) من هذا المستودع
2. افتح الملف في أي متصفح حديث (Chrome, Firefox, Edge, Safari)
3. ابدأ القراءة والاستفادة!

### الطريقة الثانية: تحويل إلى PDF

1. افتح الملف في متصفح **Google Chrome**
2. اضغط `Ctrl + P` (أو `Cmd + P` على macOS)
3. اختر **Save as PDF**
4. فعّل خيار **Background graphics**
5. اضغط **Save**

## 💻 تشغيل الأمثلة البرمجية

### باستخدام OWL Python Editor (موصى به)

```bash

git clone https://github.com/Hdoughmosch/owl_python_editor.git
cd owl_python_editor

# تشغيل المحرر
```
